# Barrera Automática

![Imagen de la barrera construida](https://github.com/lobotic/Proyectitos/blob/master/Echidna/BarreraAutomatica/barreraautomaticaportada.jpg)

Una barrera que se levanta automáticamente cuando un vehículo se pone delate de ella. Da paso con una luz verde en un semáforo.
