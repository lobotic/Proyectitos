# El Laboratorio del Dr. Frankestein

![Portada](https://github.com/lobotic/Proyectitos/blob/master/Echidna/LaboratorioFrankestein/laboratoriofrankestein.png)

## Descripción
En el laboratorio de Frankenstein probaremos la conductividad de los materiales, y el monstruo despertará cuando pongamos entre los bornes algo conductor.

Esta actividad parte de una idea original de José Manuel Padilla y se ha desarrollado con la colaboración de Susana Alonso y Eva Marín.
