# Tendedero

Tendedero automático con bloques de construcción, un servomotor y la placa EchidnaBlack2.
El sensor conectado a la entrada digital D4 vigila las condiciones del exterior y, según su lectura, el servomotor conectado a D7 mueve el tendedero entre dos posiciones: 90º cuando el sensor se activa y 150º cuando está en reposo. El programa comprueba el sensor continuamente, de modo que el tendedero cambia de posición en cuanto cambian las condiciones.
